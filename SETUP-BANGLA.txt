MINHAJ ONLINE APPS — ফোন দিয়ে সেটআপ

এটি একটি সত্যিকারের online database version:
- Home page: index.html
- Admin: admin.html
- Database: Supabase
- Free static hosting: GitHub Pages
- Admin থেকে App/Prompt add/delete করলে Home page-এ online data বদলাবে।

ধাপ 1 — Supabase
1. supabase.com-এ account খুলুন/login করুন।
2. New project তৈরি করুন।
3. Project তৈরি হলে SQL Editor খুলুন।
4. এই ZIP-এর supabase.sql ফাইলের পুরো code কপি করে SQL Editor-এ paste করুন।
5. Run চাপুন।
6. Authentication > Users-এ একটি admin email/password user তৈরি করুন।
7. ওই user-এর User ID/UUID কপি করুন।
8. SQL Editor-এ এই command চালান:
   insert into public.admin_users (user_id) values ('আপনার-UUID');
9. Project Settings-এর API/Connect অংশ থেকে Project URL এবং Publishable key নিন।
   Browser code-এ শুধু publishable/anon key ব্যবহার করবেন। service_role key দেবেন না।

ধাপ 2 — config.js
config.js খুলে:
const SUPABASE_URL = "PASTE_YOUR_SUPABASE_URL";
const SUPABASE_KEY = "PASTE_YOUR_PUBLISHABLE_KEY";

এর জায়গায় নিজের URL ও Publishable key বসান।

ধাপ 3 — ফোনে পরীক্ষা
Acode/Spck Editor-এ folder-এর সব ফাইল রাখুন।
index.html Preview করুন।
admin.html Preview/hosted URL খুলে login করুন।

ধাপ 4 — GitHub Pages-এ Online
1. GitHub-এ নতুন PUBLIC repository করুন।
2. এই folder-এর সব ফাইল upload করুন।
3. Settings > Pages খুলুন।
4. Source হিসেবে আপনার main branch/root নির্বাচন করুন এবং Save দিন।
5. GitHub Pages একটি live URL দেবে।
GitHub Pages static HTML/CSS/JS site host করতে পারে।

ধাপ 5 — Admin
আপনার live URL-এর শেষে /admin.html লিখে খুলবেন।
উদাহরণ:
https://YOUR-USERNAME.github.io/YOUR-REPO/admin.html

Admin login করার পর:
- App add
- Prompt add
- Delete
করতে পারবেন।

গুরুত্বপূর্ণ:
- service_role key কখনো config.js-এ দেবেন না।
- RLS policy এই project-এ admin_users দিয়ে write access সীমাবদ্ধ করে।
- Image upload এখন URL দিয়ে করা হয়েছে। চাইলে পরের ধাপে Supabase Storage দিয়ে সরাসরি ছবি upload system করা যাবে।
